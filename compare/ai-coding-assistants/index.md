<section class="page-hero"><div class="shell"><span class="eyebrow">Compare approaches</span><h1>An assistant helps with a task. A team owns a work loop.</h1><p>Both approaches can be useful. The distinction is the unit of responsibility: a prompt or coding session versus a measurable objective carried through coordinated roles.</p><div class="page-meta"><span>Educational comparison</span><span>No competitor performance claims</span></div></div></section>

<section class="content-section"><div class="shell"><div class="data-table-wrap"><table class="data-table"><thead><tr><th>Dimension</th><th>Typical coding assistant</th><th>Deep Navy</th></tr></thead><tbody><tr><td>Starting point</td><td>A user prompt, file, or implementation task</td><td>A business objective and proposed KPIs</td></tr><tr><td>Operating model</td><td>One user directs one assistant or session</td><td>Persistent product, design, engineering, reliability, and review roles coordinate</td></tr><tr><td>Continuity</td><td>Usually tied to the active session or supplied context</td><td>Durable team, objective, initiative, and workspace records</td></tr><tr><td>Delivery</td><td>Code suggestions or user-directed changes</td><td>Issues, branches, checks, reviews, and draft pull requests through a GitHub App</td></tr><tr><td>Control</td><td>User reviews generated output</td><td>Repository scope plus policy-driven approval gates and server-side authorization</td></tr><tr><td>Visibility</td><td>Conversation and local change history</td><td>Normalized team activity, A2A, tools, diffs, approvals, and sessions</td></tr><tr><td>Economics</td><td>Seat or usage pricing</td><td>Cost attribution by customer, team, role, objective, and initiative</td></tr></tbody></table></div><div class="callout" style="margin-top: 2rem"><strong>Choose the smallest system that fits the work</strong><p>For a bounded edit with an engineer in the loop, a coding assistant may be ideal. Deep Navy is intended for a longer-running objective that benefits from role specialization, coordination, approval, and outcome context.</p></div></div></section>
