<section class="page-hero"><div class="shell"><span class="eyebrow">Architecture</span><h1>A thin platform around strong, replaceable systems.</h1><p>Deep Navy keeps customer and business semantics in its own contracts while relying on established systems for identity, source control, billing, orchestration, inference, and observability.</p><div class="page-meta"><span>AWS</span><span>EKS</span><span>Protobuf-first</span></div></div></section>

<section class="content-section"><div class="shell content-grid"><header><span class="eyebrow">Request path</span><h2>Browser to isolated runtime.</h2></header><ol class="timeline"><li><div><h3>Static customer site</h3><p>Jekyll on GitHub Pages renders public pages and the authenticated application shell. It contains no private credentials.</p></div></li><li><div><h3>Cognito identity</h3><p>A separate user pool per environment issues the user identity through authorization code plus PKCE.</p></div></li><li><div><h3>Versioned platform API</h3><p>ConnectRPC services enforce authorization and own customer, objective, initiative, approval, billing, and aggregated view semantics.</p></div></li><li><div><h3>Durable data and services</h3><p>Aurora PostgreSQL stores the source-of-truth records. Dedicated services handle GitHub integration, streaming, economics, and provisioning.</p></div></li><li><div><h3>Per-team runtime</h3><p>The provisioner creates a namespace and one OpenClawInstance for the customer team. Six agents use separate workspaces within its Gateway.</p></div></li><li><div><h3>Inference and observability</h3><p>Model calls route through self-hosted LiteLLM to Amazon Bedrock. Langfuse provides model trace observability, while Deep Navy retains its own durable business records.</p></div></li></ol></div></section>

<section class="content-section"><div class="shell content-grid"><header><span class="eyebrow">Ownership</span><h2>Each system has one job.</h2></header><div class="data-table-wrap"><table class="data-table"><thead><tr><th>System</th><th>Responsibility</th><th>Not the source of truth for</th></tr></thead><tbody><tr><td>GitHub</td><td>Repositories, issues, pull requests, reviews</td><td>Customer identity, subscriptions, economics</td></tr><tr><td>Cognito</td><td>Deep Navy user identity</td><td>Repository and team membership</td></tr><tr><td>Stripe</td><td>Checkout, invoices, payments, subscriptions</td><td>Provisioning state or engineering cost detail</td></tr><tr><td>OpenClaw</td><td>Agent runtime, sessions, workspaces, A2A</td><td>Business objectives and durable economics</td></tr><tr><td>LiteLLM</td><td>Model routing, retry, limits, provider usage</td><td>Customer-facing product semantics</td></tr><tr><td>Langfuse</td><td>Model trace observability</td><td>Organizations, initiatives, outcomes</td></tr><tr><td>Deep Navy</td><td>Coordination, authorization, approvals, economics</td><td>Raw source-control or payment-provider records</td></tr></tbody></table></div></div></section>
