<section class="page-hero"><div class="shell"><span class="eyebrow">Architecture reference / v0.1</span><h1>System ownership is explicit at every request boundary.</h1><p>deep navy owns customer and product-work contracts. Cognito, GitHub, Stripe, Kubernetes, model routing, and observability each retain a defined infrastructure responsibility.</p><div class="page-meta"><span>Source / engineering requirements</span><span>Updated July 17, 2026</span></div></div></section>

<section class="content-section"><div class="shell content-grid"><header><span class="eyebrow">Request path</span><h2>Browser to isolated runtime.</h2></header><ol class="timeline"><li><div><h3>Static customer site</h3><p>Jekyll on GitHub Pages renders public pages and the authenticated application shell. It contains no private credentials.</p></div></li><li><div><h3>Cognito identity</h3><p>A separate user pool per environment issues the user identity through authorization code plus PKCE.</p></div></li><li><div><h3>Versioned platform API</h3><p>ConnectRPC services enforce authorization and own customer, objective, initiative, approval, billing, and aggregated view semantics.</p></div></li><li><div><h3>Durable data and services</h3><p>Aurora PostgreSQL stores the source-of-truth records. Dedicated services handle GitHub integration, streaming, economics, and provisioning.</p></div></li><li><div><h3>Per-team runtime</h3><p>The provisioner creates a namespace and one OpenClawInstance for the customer team. Six agents use separate workspaces within its Gateway.</p></div></li><li><div><h3>Inference and observability</h3><p>Model calls route through self-hosted LiteLLM to Amazon Bedrock. Langfuse provides model trace observability, while deep navy retains its own durable business records.</p></div></li></ol></div></section>

<section class="content-section"><div class="shell content-grid"><header><span class="eyebrow">Ownership register</span><h2>Each system has one durable responsibility.</h2></header><div class="data-table-wrap"><table class="data-table"><thead><tr><th>System</th><th>System of record for</th><th>Adjacent records</th></tr></thead><tbody><tr><td>GitHub</td><td>Repositories, issues, pull requests, reviews</td><td>Customer identity, subscriptions, economics remain in their owning systems</td></tr><tr><td>Cognito</td><td>deep navy user identity</td><td>Repository access and team membership remain platform records</td></tr><tr><td>Stripe</td><td>Checkout, invoices, payments, subscriptions</td><td>Provisioning state and attributed usage remain platform records</td></tr><tr><td>OpenClaw</td><td>Agent runtime, sessions, workspaces, A2A</td><td>Objectives and economics remain durable platform records</td></tr><tr><td>LiteLLM</td><td>Model routing, retries, limits, provider usage</td><td>Customer product semantics remain platform contracts</td></tr><tr><td>Langfuse</td><td>Model trace observability</td><td>Organizations, initiatives, and outcomes remain platform records</td></tr><tr><td>deep navy</td><td>Coordination, authorization, approvals, economics</td><td>GitHub and Stripe retain their provider records</td></tr></tbody></table></div></div></section>
