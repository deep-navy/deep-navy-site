<section class="page-hero"><div class="shell"><span class="eyebrow">GitHub integration</span><h1>Repository access your organization controls.</h1><p>Customers install a GitHub App, choose the repositories, and can revoke the installation in GitHub. Deep Navy does not ask for long-lived personal access tokens.</p><div class="page-meta"><span>GitHub App</span><span>Short-lived tokens</span><span>Selected repositories</span></div></div></section>

<section class="content-section"><div class="shell content-grid"><header><span class="eyebrow">Installation flow</span><h2>Bound to the signed-in organization.</h2></header><ol class="timeline"><li><div><h3>Request an installation link</h3><p>The authenticated app asks the GitHub service for a server-generated URL associated with the current Deep Navy organization.</p></div></li><li><div><h3>Install on GitHub</h3><p>A GitHub organization owner reviews the App identity and requested permissions on GitHub.</p></div></li><li><div><h3>Select repositories</h3><p>Choose only the repositories this engineering team should use. Repository selection can be changed later in GitHub.</p></div></li><li><div><h3>Verify the installation</h3><p>The server validates GitHub's callback state and records the installation-to-organization mapping.</p></div></li><li><div><h3>Mint access when needed</h3><p>Services create short-lived installation tokens for scoped operations. The browser and agent workspaces do not receive the App private key.</p></div></li></ol></div></section>

<section class="content-section"><div class="shell content-grid"><header><span class="eyebrow">Working model</span><h2>GitHub remains the delivery record.</h2></header><div class="prose"><p>Engineering agents work in branches and produce issues, commits, checks, draft pull requests, review comments, and final pull requests through the GitHub App installation. Deep Navy links those artifacts to initiatives and objectives.</p><div class="callout"><strong>Install only from a verified flow</strong><p>Start in the signed-in Deep Navy application and inspect the GitHub-owned authorization page. If the application cannot obtain an installation link from the API, it reports the integration as unavailable and does not substitute a fake success state.</p></div><p>For runtime boundaries and credential handling, read <a href="{{ '/security/' | relative_url }}">Security</a>.</p></div></div></section>
