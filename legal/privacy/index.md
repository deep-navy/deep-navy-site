<section class="page-hero"><div class="shell"><span class="eyebrow">Legal</span><h1>Privacy notice</h1><p>This early-access notice explains the public site and onboarding shell. Customer-specific processing terms are agreed before production data is connected.</p><div class="page-meta"><span>Effective July 17, 2026</span></div></div></section>
<section class="content-section"><div class="shell prose"><h2>Public site</h2><p>The public site is static content hosted with GitHub Pages. deep navy does not include third-party advertising scripts or behavioral analytics in this release. Hosting providers may process standard request metadata such as IP address, user agent, requested URL, and timestamp for delivery and security.</p><h2>Customer account and onboarding</h2><p>When the environment is configured, Amazon Cognito processes authentication. deep navy services process account identifiers, organization membership, GitHub installation metadata, subscription state, invoice history, and engineering-team records required to provide the service.</p><p>The browser briefly stores an OAuth state value and PKCE verifier in session storage. Tokens and Stripe Checkout client secrets are retained in memory and are not written to local storage by this application shell.</p><h2>Connected services</h2><p>GitHub processes App installation and repository selection. Stripe renders encrypted payment fields in an isolated Embedded Checkout iframe, processes payment information, and hosts invoice and receipt pages linked from billing history. deep navy does not receive or store card numbers or security codes in the static site.</p><h2>Early-access terms</h2><p>Retention, subprocessors, data location, export, deletion, and contractual roles are documented in the agreement for each founding customer. Before general availability, this notice will be expanded to describe the production service in full.</p><h2>Contact</h2><p>Send privacy questions or requests to <a href="mailto:privacy@deep.navy">privacy@deep.navy</a>. Do not include credentials, tokens, source code, or payment details in email.</p></div></section>
